🎥 Codegen Recording Guide

Step 1 — Browser opens: A Chromium window opens with a live code recorder panel. This is Playwright Codegen — the real recorder, not the debugger.

Step 2 — Record your actions: Click, type, and navigate in the browser. Every action is captured as Playwright code automatically in real-time.

Step 3 — Close the browser: When you have finished recording, close the Chromium window. The code is auto-saved.

Step 4 — Code auto-fills: The recorded code appears in the textarea below automatically. Review it, then click "Sync & Save Action".

💡 You can also paste codegen output manually into the textarea at any time.
